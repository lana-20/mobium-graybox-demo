Silent unless the app was launched with the gray box on: -MobiumGrayBox YES on iOS, the intent extra MobiumGrayBox=true on Android. A person running the same build never turns it on.

The whole contract is these lines: an os_log subsystem, dev.mobium.graybox, on iOS, at the notice level with values public; logcat, tag MobiumGrayBox, on Android. iOS keeps a launch argument for that launch only; a launch from the home screen carries no intent extra. So the build you test is the build you could hand anyone, and nothing in it talks unless the test asked.
