One script, four acts, the evidence kept

$ scripts/demo.sh emulator-5554   # or a simulator, or a phone

actwhat it does
1launched normally: Refresh quietly, then Row B
2the same two taps, launched with --gray-box
3the same as a test, five times each way: flaky and steady
4work that never ends; on virtual devices, a crash mid-work

Each act keeps a screen recording, a trace, screenshots, the test reports and a transcript of every command with what it printed.

The script and every run's evidence are in the demo repository; evidence/README.md is generated from each run's summary, so no number in it is typed by hand. A run ends by taking this machine's paths out of its evidence. On a real phone everything recorded is the app's own screen; the crash, which leaves the app, runs only on a virtual device.
